# AI-Medical-Bill-Parser
This project provides a proof-of-concept for an AI-powered service that automates the extraction of financial data from medical bills. This project effeciently streamlined the data exatraction specifically for various amounts in a bill that can be used as an imporatnt deciding factors in providing medical assistance.
The service operates on a 4-step pipeline as outlined in the project specification:


Step 1: OCR & Raw Token Extraction 


Step 2: Amount Normalization 


Step 3: Contextual Classification 


Step 4: Final Structured Output
