# AI-Medical-Bill-Parser
This project provides a proof-of-concept for an AI-powered service that automates the extraction of financial data from medical bills. For an employee health insurance provider like Plum, this tool can significantly streamline the claims processing workflow by reducing manual data entry, minimizing errors, and accelerating reimbursement times for members.
The service operates on a 4-step pipeline as outlined in the project specification:


OCR & Raw Token Extraction 


Amount Normalization 


Contextual Classification 


Final Structured Output
